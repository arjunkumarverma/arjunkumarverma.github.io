## 🚀 How to Push to GitHub & Deploy in 2 Minutes

### Step 1: Push Code to Your GitHub Repository
Open your computer's terminal in this project folder:
```bash
git init
git add .
git commit -m "Dr. Arjun Kumar Verma Executive Portfolio in Pure HTML/CSS/JS"
git branch -M main
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your repository on **GitHub.com**.
2. Click **Settings** ➔ **Pages** (on the left menu).
3. Under **Build and deployment**:
   - **Source**: Select **Deploy from a branch**.
   - **Branch**: Select **`main`**.
   - **Folder**: Select **`/ (root)`** (or `/docs`).
4. Click **Save**.
5. Wait ~20 seconds. Your portfolio is live at:
   ```
   https://<YOUR-GITHUB-USERNAME>.github.io/<YOUR-REPO-NAME>/
   ```
